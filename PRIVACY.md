# Privacy Policy

**Last updated: August 19, 2026**

## Overview

This application is a personal training, recovery, and wellness analysis tool that connects Oura data with workout data in ChatGPT.

The application is intended for personal use by the application owner.

## Data Accessed

With the user's authorization, the application may access Oura data including:

* Daily readiness and activity data
* Sleep and recovery data
* Heart rate and heart rate variability
* Stress data
* Workouts and sessions
* SpO2 data
* Tags
* Personal profile information
* Other health and wellness data authorized through Oura OAuth scopes

Only data authorized by the user through Oura's OAuth consent process is accessed.

## How Data Is Used

Oura data is used only to:

* Analyze sleep, recovery, activity, and training
* Compare recovery data with workout history
* Provide personalized training and recovery insights
* Answer questions initiated by the user

Oura data is not sold, rented, or used for advertising.

## Artificial Intelligence

Oura data may be processed through ChatGPT solely to provide the analysis or response requested by the user.

The application does not intentionally use Oura data to train or improve artificial intelligence models.

The application owner has disabled the ChatGPT setting that allows conversations to be used to improve OpenAI models.

## Data Sharing

Oura data is not intentionally shared with third parties except service providers necessary to operate the application and provide the requested analysis, including Oura and OpenAI/ChatGPT.

## Data Storage

The application does not operate its own independent database for storing Oura health data.

Data may be temporarily processed or retained by the services used to provide the integration according to their respective privacy and data retention policies.

## Data Security

Access to Oura data requires OAuth authorization.

OAuth credentials and access tokens should be kept confidential and are used only to access the authorized user's Oura data.

## Revoking Access

The user may revoke the application's access to Oura data at any time through their Oura account or connected application settings.

After authorization is revoked, the application will no longer be able to retrieve new Oura data.

## Data Deletion

Because this application does not maintain its own independent database of Oura health information, deletion of data stored by Oura or OpenAI is governed by the respective account and data deletion controls provided by those services.

Users may also revoke Oura authorization to prevent future access.

## Changes to This Policy

This Privacy Policy may be updated if the application functionality or data handling practices change.

## Contact

For questions regarding this Privacy Policy or the application's use of Oura data, contact the application owner using the contact email registered with the Oura Developer application.
